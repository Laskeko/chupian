# 出片搭子 ChuPian 📸

> **抬起手机，就知怎么拍。** 开源 AI 摄影搭子——你的收藏夹，就是你的机位库和拍摄偏好库。

## 为什么做这个

每个会拍照的人都经历过这两件事：

1. **机位焦虑**：到了一个景，不知道有没有人拍过、人家怎么构图。现在的办法是打开小红书手动搜同点位，一边搜一边被对象催。
2. **拍人焦虑**：不知道当前环境该拍近景、中景还是远景，不知道被拍的人喜欢什么姿势。现拍现猜，快门按了三十张，能看的没有一张。

市面上的方案要么是纯姿势图鉴（不结合你的场景），要么是 AI 修图（不管前期）。**没人管"按下快门前的那 10 秒"。**

出片搭子把这 10 秒接管了。

## 它怎么工作

- **你的收藏夹 = 你的素材库**。把手机相册里收藏的参考图（xhs 存的、自己拍的好片）授权导入，App 离线打标建索引——不上传、不联网、不出手机。
- **抬手即匹配**。取景时，App 用当前画面和你的素材库做向量匹配：这个点位你收藏过参考图？直接半透明叠加"别人拍的角度"，往左挪两步就是这个机位。
- **场景化拍法推荐**。识别当前光线和场景（日落逆光 / 阴天柔光 / 林间斑驳……），查询内置场景知识卡，结合被拍者的偏好画像，给出 2~4 个具体拍法：什么景别、怎么构图、人站哪、手放哪。
- **取景框里画给你看**。构图框线、人物站位圈、骨架参考线实时叠加；拍完一张，选"要/不要"，下次推荐更贴合。

**不训练模型、不爬任何数据、你的相册永远不离开手机。**

## 架构一览

```
┌─────────────────────── 手机端（隐私边界）───────────────────────┐
│                                                                │
│  素材库            取景层                 叠加层                │
│  ├ 收藏夹导入       ├ 取景帧 embedding      ├ 构图框线          │
│  ├ 离线打标         ├ 点位匹配 (<1s)        ├ 站位圈            │
│  └ CLIP 向量索引    └ ML Kit 骨架          └ 骨架参考线        │
│                                                                │
│  偏好画像 (JSON)     场景知识卡库 (本地内置)                        │
└────────────────────────────┬───────────────────────────────────┘
                             │ 仅一帧画面（可关闭）
                     ┌───────▼────────┐
                     │ 云端 VLM (可插拔) │ GLM-4V-Flash / 豆包 / …
                     └────────────────┘
```

- **端云混合**：CV 匹配、骨架校验全在端侧（实时层）；场景理解和个性化推荐走云端 VLM，一次场景只调一次并缓存。**支持纯离线模式**（点位匹配 + 知识卡查询，推荐降级为查表）。
- **不锁定拍摄对象**：老婆、闺蜜、孩子、父母、你自己——每个被拍者一份独立偏好画像，切换即用。

## Roadmap

| 阶段 | 内容 |
|---|---|
| v0.1 | Android MVP：素材库导入打标、点位匹配、场景推荐、取景叠加（Kotlin + Compose + CameraX + ML Kit） |
| v0.2 | 偏好反馈闭环（要/不要回流）、纯离线模式 |
| v0.3 | 场景知识卡社区共建、姿势卡内容资产 |
| v1.0 | 稳定版 + GitHub Releases APK 持续分发 |

> 只做 Android，不做 iOS。核心逻辑（打标、索引、画像、知识卡）与数据格式保持平台无关——社区想承接 iOS 随时欢迎。

## 本地跑起来

当前处于 **M2 骨架阶段**：CameraX 取景 + ML Kit 骨架实时叠加（F4 基础层），F2/F3 为界面占位。

```bash
git clone https://github.com/Laskeko/chupian.git
cd chupian
./gradlew :app:assembleDebug   # 需要 JDK 17 + Android SDK 35
adb install app/build/outputs/apk/debug/app-debug.apk
```

或者直接用 Android Studio 打开工程同步即可。

> ML Kit 依赖 Google Play Services；无 GMS 设备的适配（切 MediaPipe Tasks）在 Roadmap 里。

详细需求见 [docs/PRD.md](docs/PRD.md)，场景知识卡初始库见 [docs/scene-cards.md](docs/scene-cards.md)。

## 参与贡献

不用写代码也能贡献：

- **场景知识卡**：某种光线/环境下怎么拍，一张卡就是一个场景。往 `docs/scene-cards.md` 提 PR。
- **姿势卡**：景别 × 姿势 × 要点的结构化清单。
- **需求反馈**：你按下快门前最纠结的是什么？开 issue 告诉我们。
